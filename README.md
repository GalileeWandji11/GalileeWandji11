## 👨‍💻 À propos

Étudiant en informatique au Cégep de Saint-Jean-sur-Richelieu. Je développe sur toutes les plateformes, le plus souvent en équipe avec Git :

- 🎮 **Jeux** : jeux 3D, jeux de gestion, énigme physique
- 🌐 **Web** : applications front et back, API REST
- 📱 **Mobile** : applications Android natives (Kotlin) et application iOS et Android multiplateforme (React Native)
- 🖥️ **Desktop** : application de bureau multiplateforme
- 🔌 **Objets connectés** : programmation embarquée sur ESP32

Mes dépôts sont en grande partie privés : je détaille ici ce que j'ai réalisé.
